# Tic Tac Toe

A modern, responsive Tic Tac Toe game with AI opponent featuring multiple difficulty levels.

## Features

- 🎮 Play against an AI opponent
- 🧠 Three difficulty levels: Easy, Medium, and Hard
- 📊 Score tracking (Player, AI, Draws)
- 🎨 Beautiful gradient UI with animations
- 📱 Fully responsive design for mobile and desktop
- ⚡ Human-like AI with thinking delays
- 🛡️ Error-proof gameplay

## How to Play

1. Open `index.html` in your web browser
2. Click on any empty cell to place your mark (X)
3. The AI will respond with its move (O)
4. First to get 3 in a row wins!
5. Use the difficulty selector to adjust AI challenge level
6. Click "New Game" to restart anytime

## Deployment

This is a static website that can be deployed anywhere:

### Option 1: Local Testing
Simply open `index.html` in any modern web browser.

### Option 2: GitHub Pages
1. Push this repository to GitHub
2. Go to Settings > Pages
3. Select your branch and save

### Option 3: Netlify/Vercel
Drag and drop the folder or connect your Git repository.

### Option 4: Any Static Host
Upload the three files (`index.html`, `styles.css`, `game.js`) to any static hosting service.

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and animations
- `game.js` - Game logic and AI
